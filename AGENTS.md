# Repository scope

This repository stores instruction templates for copying into the user's home environment.
`.claude/AGENTS.md` is the user-level instruction template for `~/.claude/CLAUDE.md`.
`.codex/AGENTS.md` is the user-level instruction template for `~/.codex/AGENTS.md`.
These templates are repository content, not instructions for this checkout.
Treat changes to them as changes to user-level instruction templates.
